# UVM Testbench Project using UBUS Protocol

### 프로젝트 개요
이 프로젝트는 UBUS 프로토콜을 이용하여 UVM 기반의 테스트벤치를 생성하는 것을 목표로 합니다.
주요 목적은 다양한 환경에서 DUT (Design Under Test)를 효과적으로 검증하는 것입니다.

### 컴파일 및 시뮬레이션 실행 방법
아래 명령어를 통해 프로젝트를 컴파일하고 시뮬레이션을 실행할 수 있습니다.

* 컴파일
`make compile`

* 시뮬레이션 실행
`make sim`

* 컴파일 및 시뮬레이션 실행
`make all`
